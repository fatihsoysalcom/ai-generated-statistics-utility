# AI Generated Statistics Utility

This example demonstrates a Python utility function that calculates basic statistics (mean, median, mode) for a list of numbers. It simulates the kind of practical, self-contained code an AI assistant like GitHub Copilot or ChatGPT could quickly generate to automate common data processing tasks, highlighting AI's role in boosting developer productivity.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
